# EsferaMapaNormal

Proyecto de Unity realizado para el primer parcial de Videojuegos.

## Descripcion

La escena contiene:

- Una esfera llamada `Esfera_Deysi`.
- Un material llamado `MaterialEsfera_Deysi`.
- Un mapa normal con el nombre `DEYSI`.
- Una luz de tipo `Point Light`.
- La esfera coloreada de rojo.

## Escena principal

La escena se encuentra en:

```text
Assets/Scenes/EscenaEsfera.unity
```

## Commits solicitados

Los cambios se realizaron en este orden:

1. `creando esfera`
2. `texturizando esfera`
3. `agregando luz`
4. `coloreando esfera de rojo`

## Como abrir el proyecto

1. Clonar este repositorio:

   ```bash
   git clone https://github.com/DeysiVarela/EsferaMapaNormal.git
   ```

2. Abrir la carpeta clonada desde Unity Hub.
3. Abrir la escena `Assets/Scenes/EscenaEsfera.unity`.
